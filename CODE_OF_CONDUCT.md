# Code of conduct

Placard is for everyone who wants to make things. We want working on it to
feel the same way.

**Expected:** be kind and patient, assume good intent, give feedback on the
work and not the person, credit others, and help newcomers.

**Not accepted:** harassment, insults, discrimination of any kind, sexual
language or imagery, personal attacks, trolling, publishing someone's private
information, and any conduct that would be inappropriate in a professional
setting.

**Scope:** the repository, issues, pull requests, discussions, and anywhere
someone represents the project.

**Reporting:** contact the maintainer privately (see the GitHub profile of
the repository owner) or use GitHub's "Report content". Reports are handled
confidentially. Maintainers may remove content, warn, or ban anyone who
breaks this code, temporarily or permanently.

This code is adapted from the ideas of the [Contributor Covenant](https://www.contributor-covenant.org/).
